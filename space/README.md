# TailDaam — live dashboard

Pakistan petrol and diesel prices, with a citation on every number.

This is the static Space frontend. It talks to the same verified API as the
FastAPI deployment at <https://hack-insight.fastapicloud.dev>:

- Overview: freshness, quality status, last pipeline run, prices and city table
- Model: held-out predictions, baseline comparison and group errors
- Insight agent: cited answers and structural refusals, in English and Urdu

The code, data pipeline, model and RAG implementation are in the
[GitHub repository](https://github.com/DanyalAbbas/hack-insight).
